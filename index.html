Estrix

An OWL 2 ontology workbench for iPhone, iPad and Mac.

Estrix opens, edits and reasons over OWL 2 ontologies on the device itself. It is built for ontologists and knowledge engineers who want the whole workbench wherever they are, with no account and no server behind it.

Opens what you already have

Estrix reads and writes nine syntaxes: Turtle, N-Triples, N-Quads, TriG, RDF/XML, JSON-LD, OWL/XML, OWL functional syntax and Manchester syntax. It holds an ontology as OWL 2 axioms, so classes, properties and axioms appear as the specification defines them rather than as triples to decode. It follows owl:imports and keeps the imported files for work offline, runs SPARQL 1.1 queries, and tells you which OWL 2 profiles an ontology falls within.

Reasons on the device, offline

Classification, consistency checking and instance retrieval run on the device, with no account and no server. An ontology you open stays there unless you choose a feature that uses the internet. Every verdict states whether it is complete. When an ontology uses a construct the reasoner does not decide, Estrix says so rather than returning a guess.

Explains its answers

For any entailment, whether one class under another, a class that can have no instances, or an individual's type, Estrix lists the axioms that justify it, and it can list every justification rather than only the first. A health check reports anything the parser could not keep, so a dropped axiom never passes in silence.

Ask, the built-in assistant, answers questions from the ontology's own axioms. It uses Apple's on-device model unless you choose a cloud provider and supply your own key.

One engine, three devices

The same model, parsers and reasoner run on iPhone, iPad and Mac, so a file behaves the same wherever you open it. On iPad and Mac, keyboard shortcuts and a command palette keep the work quick.
