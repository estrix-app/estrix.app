Support

Estrix is made by Estrix LLC. Two addresses reach the team that builds the app.

Help with the app

Write to support@estrix.app with questions, problems, and requests. A report we can act on includes:

  • the device and its system version, for example an iPhone on iOS 27;
  • the Estrix version and build number, shown on the app's opening screen;
  • what you did, what you expected, and what happened instead;
  • the ontology or its web address when you can share it, or a smaller file that shows the same problem;
  • a screenshot or screen recording when the problem is visible.

We reply from the same address. We use what you send only to reply and to improve the app, as the privacy policy says.

Reporting a security vulnerability

If you find a vulnerability in Estrix, write to security@estrix.app rather than describing it in public. Include:

  • the affected version and build number;
  • the steps that reproduce it, or an ontology or web address that triggers it;
  • the impact you believe it has.

We acknowledge a report within seven days and ask you to keep it confidential until a fix ships. Estrix runs no servers of its own, so a report usually concerns how the app reads a file or a web address, follows owl:imports, or sends a request to a cloud AI provider or to GitHub on your behalf.
