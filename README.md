# estrix.app

The public website of Estrix, the OWL 2 ontology workbench for iPhone, iPad, and Mac, published by Estrix LLC.

Static HTML and CSS, served by GitHub Pages at https://estrix.app. The pages load no scripts, fonts, or analytics from anywhere, so the site itself collects nothing.

- `index.html`: the front page
- `privacy/`: the privacy policy
- `support/`: support and security contacts
- `robots.txt` and `sitemap.xml`: tell search engines which pages exist
- `db2a9122c2fc84e8eafeb5352bb35298.txt`: the IndexNow key, which proves to Bing and other search engines that requests to crawl this site come from its owner
